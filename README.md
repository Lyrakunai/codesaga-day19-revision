## 📖 What I Learned

### ✅ Decision Making
- Used `if`, `elif`, and `else` to control program flow.
- Learned that condition order is very important.

### ✅ Logical Operators
- `and` → Both conditions must be True.
- `or` → At least one condition must be True.

### ✅ Validation
- Always check invalid input before valid conditions whenever required.

### ✅ Debugging
- Difference between `=` and `==`
- Found logical mistakes in condition order.

### ✅ Leap Year Logic
- Divisible by **400** → Leap Year
- Divisible by **100** → Not Leap Year
- Divisible by **4** → Leap Year
- Otherwise → Not Leap Year

### ✅ Last Digit
- Last digit of a number can be found using:
  ```python
  num % 10
  ```
